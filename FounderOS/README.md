
# FounderOS – AI Productivity Dashboard

## About the Project
FounderOS is a web-based AI productivity dashboard designed to help startup founders manage their daily business activities from one place.

## Features
- Dashboard with productivity statistics
- Customer Support section
- Hiring Assistant
- User Interviews
- AI Agents management
- Task management
- Workspace Settings
- Interactive buttons and notifications
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
FounderOS/
├── index.html
└── README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. The FounderOS dashboard will open in your browser.

## Note
This project is a frontend demonstration. AI responses are predefined demo responses and are not connected to a live AI service.
